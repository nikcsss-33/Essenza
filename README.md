# Essenza

Una web moderna e elegante che rappresenta l'essenza del design contemporaneo.

## Descrizione

Essenza è un sito web moderno che combina design elegante e funzionalità responsive. Il progetto include:

- Design responsive che si adatta a tutti i dispositivi
- Navigazione fluida con menu hamburger per mobile
- Sezioni dedicate: Home, Chi Siamo, Servizi, Contatti
- Animazioni e transizioni fluide
- Form di contatto interattivo

## Come Utilizzare

1. Apri il file `index.html` nel tuo browser web
2. Oppure, per un server locale, puoi usare:
   ```bash
   # Con Python 3
   python -m http.server 8000
   
   # Con Node.js (se hai http-server installato)
   npx http-server
   ```
3. Visita `http://localhost:8000` nel tuo browser

## Caratteristiche

- **Responsive Design**: Ottimizzato per desktop, tablet e mobile
- **Navigazione Fluida**: Scroll smooth tra le sezioni
- **Menu Mobile**: Hamburger menu per dispositivi mobili
- **Animazioni**: Effetti di scroll e hover per migliorare l'esperienza utente
- **Form Contatti**: Form interattivo con validazione

## Tecnologie Utilizzate

- HTML5
- CSS3 (con CSS Grid e Flexbox)
- JavaScript (Vanilla JS)
