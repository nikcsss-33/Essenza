Servidor Web

📋 Instrucciones para iniciar el servidor:
1. Abre el terminal integrado de VS Code
Presiona: Ctrl + `
2. Ejecuta uno de estos comandos:
python3 -m http.server 8080
o
python3 server.py
o
./start-server.sh
3. Abre tu navegador en:
http://localhost:8080
💡 Nota: Debido a limitaciones del entorno, el servidor debe iniciarse manualmente desde el terminal. Todos los archivos están listos y actualizados con la nueva estética editorial.
